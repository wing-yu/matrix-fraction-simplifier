# matrix-fraction-simplifier
An educational implementation of fraction simplification using a matrix recurrence derived from the Euclidean algorithm and continued fraction convergents.

This repository is shared for academic review and discussion only. It does not propose a new mathematical algorithm. Instead, it presents a compact implementation of well-established mathematics in a form that may be useful for learning, comparison, and code review.

This implementation instead uses the quotient sequence generated by the Euclidean algorithm to update a small matrix. When the algorithm terminates, the matrix directly contains the reduced numerator and denominator. The implementation is intentionally compact so that the underlying recurrence remains visible.

Design Goals
• Present the algorithm as clearly as possible.
• Remain completely iterative (no recursion).
• Use only integer arithmetic.
• Avoid `Math.floor()`.
• Compute the Euclidean remainder only once per iteration.
• Keep the matrix recurrence visible.

Suggestions, corrections, mathematical observations, and implementation comparisons are welcome.
